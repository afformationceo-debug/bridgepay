# 01. PRD (Product Requirements Document)

> LINE Unify Pay - 한국 가맹점 결제 시스템

---

## 1. Executive Summary

### 1.1 제품 개요
LINE Unify Pay는 일본/대만 관광객이 한국 병원 및 뷰티 매장에서 LINE 앱을 통해 스테이블코인으로 결제할 수 있는 시스템입니다.

### 1.2 핵심 가치 제안

| 이해관계자 | Pain Point | Solution |
|-----------|-----------|----------|
| **가맹점** | PG 수수료 2.5~3.5%, 정산 D+3~7 | 수수료 최소화, 실시간 정산 |
| **고객 (관광객)** | 환전 불편, 카드 수수료 | LINE 앱으로 원클릭, 환율 우대 |
| **Afformation** | 마케팅 대행 외 신규 BM | 결제 인프라 → 플랫폼 사업 |

### 1.3 사업 목표

```
2026년 목표:
├── 3월: MVP 런칭 (파트너 병원 10개)
├── 6월: 100개 가맹점 확보
├── 9월: 월 GMV 10억 달성
└── 12월: 올리브영 등 대형 뷰티 매장 확대
```

## 5. Feature Specifications

### 5.1 가맹점 랜딩페이지

**목적**: 가맹점 유치 및 신청 접수

**주요 화면**:
1. **Hero Section**
   - 헤드라인: "수수료 0%, 정산 1일"
   - 서브: "LINE Unify로 해외 고객 결제를 혁신하세요"
   - CTA: [가맹점 신청하기]

2. **Benefits Section**
   - 수수료 비교 (기존 PG vs Unify Pay)
   - 정산 속도 비교 (D+7 vs D+0)
   - 지원 통화 (JPY, TWD, USDT)

3. **신청 Flow**
   - Step 1: 기본 정보 (상호명, 업종, 연락처)
   - Step 2: 서류 업로드 (사업자등록증, 통장사본)
   - Step 3: 지갑 연결 (LINE Unify 지갑)
   - Step 4: 심사 대기 → 승인 → QR 발급

### 5.3 결제 QR 시스템

**QR 타입**: Static QR (MPM - Merchant Presented Mode)

**QR 데이터 구조**:
```json
{
  "version": "1.0",
  "type": "unify_pay",
  "merchant_id": "M_ABC123",
  "merchant_name": "강남피부과",
  "network": "kaia",
  "wallet_address": "0x1234...5678",
  "callback_url": "https://api.unifypay.kr/v1/callback"
}
```

**QR 디자인 요구사항**:
- 크기: 최소 3cm x 3cm
- 브랜딩: LINE Unify + Afformation 로고
- 오류 정정: Level M (15%)
- 배경: 투명 또는 흰색

| 항목 | 목표 | 측정 방법 |
|------|------|----------|

| 대시보드 로딩 | < 2초 | LCP |

### 6.2 가용성 요구사항

| 항목 | 목표 |
|------|------|
| 시스템 가용성 | 99.9% |

| 장애 복구 시간 | < 1시간 |
